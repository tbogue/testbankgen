Your reusable question bank

  1. Keep this HTML file in a permanent folder and open it in your browser. No installation or internet is needed for importing or saving.
  2. Import .tst, .doc, .docx, or .pdf files. Word and PDF imports show a question preview first. Numbered questions and lettered choices work best. Scanned PDFs need OCR before import. Extract the complete ZIP so the bundled importers stay next to this HTML file. This release supports the legacy Windows ExamView 04 format used by your Chapter 4 test. Other versions are rejected with a message.
  3. Review each question, its answer choices, diagrams, and reference answer. Imported keys are never assumed to be verified. You can edit text, tags, category, and points.
  4. Check the boxes for the questions you want. Exports follow the bank’s displayed order. Search and category filters help you choose a subset.
  5. Export Word files for paper tests or upload them to Drive and open with Google Docs. Export Moodle XML through Moodle’s Question bank → Import → Moodle XML format.
  6. For Google Forms, export the Google script. Visit script.google.com, create a project, replace the editor contents with the downloaded script, and run createGoogleForm. Authorize your account when Google asks. Run createGoogleDoc instead for a native Google Doc. The execution log shows the link. A school administrator may restrict Apps Script.
  7. For Classroom, attach the generated Form or Google Doc to an assignment yourself. This app does not post assignments or connect to your account.
  8. Save a bank backup after importing or editing. Browser storage can be cleared; a JSON backup lets you restore on another computer. Moving this HTML file may change access to its browser storage.

Review policy: Moodle and Google script exports require all selected questions to be reviewed. Multiple-choice questions also need a selected correct answer. Written responses export for manual grading, with reference answers kept teacher-side. Review placeholder answers and any questions that share a figure before exporting.

Clearing imports: Clear imported questions removes imported questions and source test records after confirmation. Manually created questions stay. A full backup download starts first, and you can then reimport the same tests.

Images: Ordinary supported bitmap images import automatically and stay attached to their questions. Image counts appear in the import report and bank list. Teacher answer images appear below the reference answer and in teacher-side exports. Embedded equation objects are a different format; unresolved equations still have visible repair markers.

Compatibility: Text and uncompressed monochrome and color bitmap diagrams are supported. Unsupported image data is flagged. Completion, short answer, problem, and essay questions import as written responses. Equations stored as objects may require manual repair; bracketed placeholders identify missing content. Other ExamView versions have not been verified. Keep your original files. Identical questions in different source files remain separate so their context is preserved.
